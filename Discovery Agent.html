Native packages, not custom installers.

The agent is compiled per OS and shipped as a signed native package — rpm for Linux, msi for Windows, installp for AIX — installed, upgraded, and removed through each platform's own package manager. Central builds, signs, and versions every package and hosts the repository servers pull from.

Package signed
01Native packaging or it doesn't ship.rpm, msi, installp. No bespoke installer frameworks.
02The agent never decides what to run.Every command comes from the central API.

04Schedules are built in, not bolted on.Scan and report cadence ships with the agent.
